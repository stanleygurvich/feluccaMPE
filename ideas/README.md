# Ideas

Ideas for this fork, kept so they are not lost. Each one says what it rests on and how sure we are:
**done** (built, tested, measured), **verified** (read in the code or measured, not built yet), or **unverified**
(a guess: check the code before building on it). Costs are measured on the device build (JieLi toolchain,
`tools/build.py`'s checks, `tests/target_budget.py`) once something is built; before that they are estimates and say so.

- [free-sources.md](free-sources.md): modulation sources that cost almost nothing, from state the firmware already has
- [performance.md](performance.md): playing ideas (MPE, routings, FX)
